# Tela de Login

Interface de login responsiva desenvolvida com HTML e CSS. O projeto foi criado para praticar estruturação semântica, estilização de formulários, responsividade e efeitos visuais modernos.

![Prévia da tela de login](docs/preview.png?v=2)

## Demonstração

[Acesse o projeto publicado](https://gustavosaless1.github.io/tela-login/)

## Funcionalidades

- Campos para e-mail e senha.
- Opção de lembrar a senha.
- Link para recuperação de senha.
- Botão com efeito ao passar o mouse.
- Layout responsivo para diferentes tamanhos de tela.
- Atalho para contato pelo LinkedIn.

> Este projeto apresenta somente a interface. A autenticação de usuários ainda não está conectada a um servidor ou banco de dados.

## Tecnologias utilizadas

- HTML5
- CSS3
- Google Fonts
- Boxicons
- Git e GitHub

## Como executar

Clone o repositório:

```bash
git clone https://github.com/GustavoSaless1/tela-login.git
```

Depois, abra o arquivo `index.html` no navegador ou utilize a extensão Live Server no VS Code.
